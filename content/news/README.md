# 뉴스 폴더

Pages CMS의 **[② 뉴스]** 탭이 관리하는 폴더입니다. 기사 한 건 = 파일 한 개입니다.

기사를 추가·수정·삭제하면 GitHub Actions가 자동으로 이 폴더의 모든 파일을
`content/news.json` 하나로 합쳐 줍니다(사이트는 그 합쳐진 파일만 읽습니다) —
직접 `content/news.json`을 고치지 마세요, 다음 저장 때 자동으로 덮어써집니다.

기사 하나당 파일 하나로 나눈 이유: 예전에는 기사들이 `content/news.json`
안에 배열 하나로 전부 들어 있어서, 관리자가 기사 한 건만 추가해도 Pages
CMS가 폼에 없던 기존 기사까지 통째로 지워버리는 사고가 있었습니다. 파일을
나누면 기사 한 건을 고칠 때 다른 기사 파일은 아예 건드리지 않습니다.

이 README는 지우지 마세요 (`.pages.yml`에서 목록에서 빼도록 설정돼 있습니다).
