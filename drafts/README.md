# 기사 초안 폴더

여기에 한국어 초안(`.md`)이 올라오면 GitHub Actions 가 자동으로
영어·일본어·중국어로 번역해 `content/news.json` 에 넣고, 초안 파일은 지웁니다.

**Pages CMS 의 `⑤ 기사 초안` 에서 쓰는 것이 가장 편합니다.**
제목·분류·날짜·본문 칸만 채우고 저장하면 나머지는 자동입니다.

## 직접 파일로 올릴 때

```text
---
title: 싱가포르 BC4:2025 개정 관련 기술 세미나 개최
category: 언론보도
date: 2026-08-12
link: https://example.com/article
---
센 엔지니어링그룹은 싱가포르 건설청 (BCA) 과 함께 PSRC 공법에 관한
기술 세미나를 개최했다.

문단은 빈 줄로 나눕니다.
```

머리말 없이 **첫 줄 제목 / 빈 줄 / 본문** 만 적어도 됩니다.
그때는 분류가 `언론보도`, 날짜는 오늘로 들어갑니다.

## 알아 두실 점

- **고유명사는 용어집(`content/glossary.json`) 표기를 그대로 씁니다.**
  용어집에 없는 말은 번역기가 임의로 옮기므로, 중요한 이름은 먼저
  Pages CMS `④ 용어집` 에 넣어 주세요.
- 번역 결과는 저장소 **Actions** 탭에서 확인할 수 있습니다.
  용어집과 다르게 번역된 항목이 있으면 경고가 찍힙니다.
- 이 `README.md` 는 번역 대상에서 제외됩니다.
