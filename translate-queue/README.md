# 번역 요청 폴더

Pages CMS의 **[⑤ 번역 요청]** 탭이 관리하는 폴더입니다. 직접 파일을
만들 필요는 없고, Pages CMS에서 다음 순서로 씁니다.

1. **[② 뉴스]**에 한국어로 기사를 먼저 올리고 "고유 ID"를 확인합니다.
2. **[⑤ 번역 요청]** → 새 항목 추가 → "번역할 기사 ID"에 그 ID를 붙여넣고 저장합니다.
3. 저장된 항목을 열어 **"번역 시작"** 버튼을 누릅니다.
4. GitHub Actions가 그 기사를 용어집 기반으로 번역해
   `content/news-i18n.json`에 기록하고, 처리한 이 폴더의 요청 파일은
   자동으로 지웁니다 — 결과는 **[⑥ 번역]** 탭에 나타납니다.
